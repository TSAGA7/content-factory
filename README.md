# CONTENT FACTORY

Персональная система управления контентом: бренды, аккаунты Telegram / Instagram / YouTube / Threads, генерация текстов и контент-планов через Claude, календарь, очередь и автопубликация по расписанию — даже когда браузер закрыт.

## Что работает в этой версии

| Модуль | Состояние |
|---|---|
| Вход (персональное приложение: регистрация закрывается после первого пользователя) | ✅ |
| Бренды: тон, аудитория, рубрики, запреты, CTA, примеры | ✅ |
| Аккаунты: Telegram через своего бота (проверка прав), тестовые mock-аккаунты, пауза, отключение | ✅ |
| Автопилот: 4 режима, окна, запретные даты, лимиты, интервал, поведение при ошибках | ✅ |
| Редактор: версии с восстановлением, оптимистическая блокировка, проверка лимитов площадки, медиа, комментарии, журнал | ✅ |
| Claude: публикация по теме, переписать/сократить/расширить/тон, варианты, сценарий Reels/Shorts, метаданные YouTube, проверка качества, контент-план → идеи, адаптация копий под другие аккаунты | ✅ (нужен ключ Anthropic) |
| Календарь: день / неделя / месяц / список, фильтры | ✅ |
| Медиатека: приватный бакет, метаданные, SHA-256, теги, защита от удаления используемых файлов | ✅ |
| Очередь: `FOR UPDATE SKIP LOCKED` + аренда, контрольные точки, backoff, лимиты без расхода попыток, ручная сверка неизвестного результата, аварийная остановка | ✅ |
| Публикация Telegram: текст, фото, видео, альбом | ✅ |
| Публикация Instagram, YouTube, Threads (OAuth) | ⬜ следующая итерация — можно планировать на mock-аккаунтах |

## Архитектура

```
React SPA (GitHub Pages) ──JWT──► Supabase: Postgres (RLS, триггеры, RPC) · Storage · Vault
                                     │
                     pg_cron (1 мин) ─┴─► Edge Function `cf` → publish-worker / maintenance
                                         posts-schedule · ai-generate · accounts-connect · app-settings
                                         └─► Telegram Bot API · Anthropic API
```

- `supabase/migrations` — схема, RLS, защитные триггеры, RPC движка, зашифрованные учётные данные (`secure`), Storage, cron.
- `supabase/functions/_shared` — доменный слой (общий с фронтендом), движок очереди, адаптеры площадок, Claude, шифрование.
- `supabase/functions/cf` — одна развёртываемая функция-маршрутизатор `/functions/v1/cf/<route>`.
- `src/` — интерфейс (React, TanStack Query, Tailwind), полностью на русском и адаптивный.

Секреты: ключ шифрования токенов, секрет worker'а и ключ Anthropic хранятся в **Supabase Vault** (ключ Claude вводится в «Настройках» и в браузер не возвращается). Переменные окружения функций имеют приоритет над Vault.

## Разработка

```bash
npm ci
npm run dev                 # http://localhost:5173 (значения в .env.production / .env.local)
npm run typecheck && npm run build
npm run test:functions      # deno: домен, адаптер Telegram, редактирование секретов
```

Развёртывание и настройка — [docs/DEPLOY.md](docs/DEPLOY.md).
